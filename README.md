# An-AI-agent-

A personal project exploring human-AI collaborative coding. Built as part of my journey in Computer Science and Engineering to understand AI ethics, prompt engineering, and code ownership.

Currently, this repository features a **Basic Rule-Based AI Assistant** built in Python that can handle greetings, answer basic questions, and perform simple mathematical calculations.

## Features
* **Interactive Chat Loop:** Runs continuously in the terminal until the user exits.
* **Command Parsing:** Recognizes keywords for specific outputs (e.g., "python", "ai", "study").
* **Safe Calculator:** Includes a math evaluation function with error handling for division by zero and invalid characters.
